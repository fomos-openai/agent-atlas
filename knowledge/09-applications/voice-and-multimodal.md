# 语音与多模态 Agents

实时 Agent 需要语音活动检测、打断、低延迟工具和多模态状态同步。语音确认应重复关键实体与数字，敏感动作转入结构化确认。

评测覆盖转写错误、噪声、口音、抢话、延迟和错误工具调用。录音与图像具有更高隐私成本，应显式告知并限制留存。
