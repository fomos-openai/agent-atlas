# 机器人与 Embodied Agents

具身 Agent 将感知、空间表示、规划、技能和低层控制结合。语言模型适合高层任务解释与技能选择，实时安全控制仍应由确定性控制器承担。

仿真到现实存在感知误差与动力学差异。物理急停、速度/区域限制、碰撞检测和人工监督不能依赖语言模型。
