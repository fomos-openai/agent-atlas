# 客户运营 Agents

Agent 可整合账户、知识库和历史交互，生成回复、更新工单或执行有限补救。涉及承诺、退款、价格和隐私时使用规则与人工审批。

评测按问题解决率、事实正确、政策遵循、升级质量和客户结果分层，避免只优化回复流畅度。
