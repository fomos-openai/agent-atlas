# 研究、数据与科学 Agents

这类 Agent 分解问题、搜索一手资料、执行代码、检查数据质量并综合结论。产物必须保留查询、数据版本、代码、假设和引用，使结果可复现。

防止把搜索排名当证据、把相关性当因果或把模型生成数据混入真实数据。高影响科学结论需要领域专家复核。
