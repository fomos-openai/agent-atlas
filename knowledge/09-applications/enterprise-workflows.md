# 企业工作流 Agents

企业场景的价值来自跨系统理解非结构输入并推进流程。稳定步骤保持 workflow，Agent 处理分类、信息补全、异常调查和建议。写回系统前应用身份、审批和幂等。

成功指标是周期、返工、人工负担和业务结果，不是对话数量。部署从只读建议和草稿模式开始。
