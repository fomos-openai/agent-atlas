# 阅读路径

- **应用工程师**：核心机制 -> 单 Agent 模式 -> 生命周期 -> 评测 -> 五个实验。
- **平台架构师**：参考架构 -> 持久执行 -> MCP/A2A -> 可观测性 -> 安全治理。
- **产品负责人**：定义与边界 -> 机会发现 -> 成熟度 -> 经济模型 -> Build or Buy。
- **安全与治理**：威胁模型 -> 最小权限 -> 记忆安全 -> 事件响应 -> 生产就绪清单。
- **研究者**：历史时间线 -> 推理/反思 -> Benchmark -> 开放研究问题 -> 未来信号。

不要从框架列表开始。先定义任务、环境、失败成本和验收证据，再选择实现。
