# 核心术语表

本页由 `catalog/glossary.yaml` 维护。核心区分包括：Agent 是自主闭环；Workflow 是预定义控制流；Trajectory 是完整运行轨迹；Guardrail 是自动边界控制；Human-in-the-loop 是人工审批或复核；MCP 面向工具与上下文连接；A2A 面向独立 Agent 协作；Durable execution 表示可持久化、等待和恢复的运行。

术语必须服从上下文。例如“memory”可能指当前对话历史、外部向量检索、结构化用户档案或任务状态，设计文档应指明具体语义、作用域和保留期限。
