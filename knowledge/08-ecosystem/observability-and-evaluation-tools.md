# 可观测与评测工具

工具应支持跨模型与框架的运行 ID、模型/工具 span、数据脱敏、反馈、数据集版本和实验比较。OpenTelemetry 等开放语义有助避免观测锁定。

采购时检查数据驻留、采样、成本、评分器复现和原始轨迹导出。漂亮的 trace UI 不能替代业务结果关联和发布门禁。
