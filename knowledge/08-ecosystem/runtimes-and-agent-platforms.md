# 运行时与 Agent 平台

运行时执行单个闭环，平台进一步管理定义、版本、部署、身份、配额、观测和治理。选择托管或自建取决于数据边界、工具网络、控制需求和运维能力。

关键评审项是恢复语义、状态导出、策略可插拔、追踪完整性、模型可替换和成本归因，而不是 Playground 体验。
