# 模型与提供商

Agent 模型选择关注指令遵循、工具调用、长上下文、结构化输出、多模态、延迟、价格、地域和数据政策。一个运行可按步骤路由不同模型，但路由本身要评测。

不要把厂商排行榜直接映射到业务。使用同一任务集比较成功率、轨迹违规和总成本，并记录精确模型快照。模型升级视为代码变更，必须回归。
