# 经济性与运营模型

完整成本包括模型、搜索、工具、沙箱、存储、观测、人工审批、失败返工和安全运营。Agent 的价值是提高完成率、缩短周期或扩大可处理范围，而不是单纯减少人力。

运营团队需要 Agent Owner、领域专家、平台、安全和评测协作。每个生产 Agent 都应有预算、SLO、值班路径、变更记录和退出机制。
