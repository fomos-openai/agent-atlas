# 生产成熟度

成熟应用多为有界任务：编码辅助、企业知识检索、客服草稿、数据分析和内部流程调查。它们有明确工具、可检查结果、人工升级和回滚路径。

涉及资金、医疗、法律、公共安全或大规模不可逆动作时，应将 Agent 限制为建议或分步审批。生产成熟度来自系统控制和运营证据，而非模型自主性。
