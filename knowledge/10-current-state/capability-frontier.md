# 能力前沿

Agent 在有反馈和可验证产物的环境中进步最快：代码可测试、网页可观察、数据分析可执行。困难仍集中在模糊目标、长依赖链、隐藏状态、脆弱 UI 和跨域权限。

前沿演示不能直接外推生产可靠性。任务长度增加时，单步小误差会复合；环境变化和恢复能力往往比模型静态基准更决定结果。
