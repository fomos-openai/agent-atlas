# Agent 从哪里来

LLM Agent 不是凭空出现的新物种。它继承了经典 AI 对“感知-行动”的问题定义、规划对未来步骤的搜索、强化学习对回报与探索的处理，以及软件工程对状态机、工作流和分布式系统的积累。Foundation Models 把语言理解、世界知识和通用接口压进同一个模型，使自然语言成为规划与工具编排的通用层。
