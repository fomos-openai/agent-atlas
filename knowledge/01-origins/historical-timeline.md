# 历史时间线

- **1995**：BDI 将信念、愿望和意图带入可执行 Agent 讨论。
- **2017**：Transformer 奠定大规模通用序列模型基础。
- **2022**：Chain-of-Thought 与 ReAct 连接显式推理和环境行动。
- **2023**：工具、反思、长期记忆、开放环境与 Agent Benchmark 集中发展。
- **2024**：工程社区开始明确区分预定义 workflow 与动态 agent。
- **2025**：MCP、A2A 等协议推动工具与 Agent 的互操作。
- **2026**：持久运行时、全轨迹评测、最小权限、人工控制和可运营性成为主战场。
