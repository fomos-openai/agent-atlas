# LLM Agent 里程碑

2022 年的 Chain-of-Thought 与 ReAct 展示了分解问题及交错推理与行动；2023 年 Toolformer 探索工具使用学习，Generative Agents 展示记忆-反思-计划架构，Reflexion 使用语言反馈改进重试，Voyager 将技能库与开放环境探索结合。随后工程焦点从“能否行动”转为“能否可靠、经济、可治理地长期行动”。

这些工作不应被读成一条单向能力曲线。不同任务对规划深度、反思次数和记忆结构的收益不同；更多循环也可能带来成本、漂移和攻击面。
