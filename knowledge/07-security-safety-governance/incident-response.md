# Agent 事件响应

预案包含一键暂停 Agent、禁用工具、撤销凭据、隔离记忆、终止在途任务和阻断远程连接。调查需保存版本、轨迹、审批、策略判定和外部系统日志。

恢复前确认副作用范围，必要时执行补偿。事后将事件转成评测用例、策略或工具修复，并审查相邻能力，避免只修复一个提示字符串。
