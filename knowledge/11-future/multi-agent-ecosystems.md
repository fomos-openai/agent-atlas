# 多 Agent 生态

开放协议可能让专业 Agent 像服务一样被发现和组合。真正难点不是通信，而是身份、服务质量、价格、数据边界、委托深度和争议处理。

早期更可能在单组织或受信联盟中成熟，而非完全开放市场。互操作测试套件和责任可追踪性是关键领先指标。
