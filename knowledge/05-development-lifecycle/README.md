# Agent 研发与生产生命周期

生命周期不是“写提示词 -> 上线”。它从任务与风险定义开始，经最小原型、轨迹评测、安全测试、分阶段发布、生产观测与持续改进，最终以权限撤销和数据归档结束。每一阶段都有明确进入和退出证据。
