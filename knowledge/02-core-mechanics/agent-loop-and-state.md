# Agent Loop 与状态

典型循环是：读取目标和状态，选择模型与上下文，模型返回消息或工具调用，运行时验证并执行，观察结果写回轨迹，随后判断成功、继续、暂停或失败。真正的控制点位于循环外层，而不是提示词里。

状态至少分为会话消息、结构化任务状态、工具产生的环境状态和可恢复检查点。混在一个消息列表里会让重试、审计和恢复变得脆弱。运行时应设置最大步数、时间、Token、费用、工具次数和连续失败阈值，并让终止原因成为可观测字段。
