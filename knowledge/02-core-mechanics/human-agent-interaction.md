# 人机协作

人在回路不应只在最终弹出“确认”。良好交互让用户在开始时理解能力和边界，运行中看到计划、证据与消耗，在关键副作用前获得具体审批，在失败时能够纠错、缩小范围或接管。

审批信息应说明对象、动作、影响、可逆性和替代方案。过多低价值确认会造成批准疲劳；过少则失去控制。系统应根据风险分层：安全只读自动执行，可逆写操作批量预览，不可逆或高影响动作逐项批准。
